# 시안 A/B/C 레이아웃 차별화 강화

**날짜:** 2026-05-31  
**파일:** `src/lib/variant-refs.ts`  
**목표:** 3개 시안이 같은 디자인 시스템을 쓰면서도 카드 크기/배치가 구조적으로 다르게 나오도록 PHILOSOPHY 텍스트에 비율·크기·금지 패턴 제약을 추가한다.

---

## 문제

현재 PHILOSOPHY_A/B/C는 "정보를 비교하기 쉽게", "CTA를 강조" 같은 **의도** 설명만 있고, 카드가 얼마나 커야 하는지/얼마나 많이 보여야 하는지를 강제하지 않는다. 결과적으로 AI가 세 시안 전부 "중간 크기 카드 3-4개" 기본값으로 만들어 시각적 차이가 없다.

---

## 설계 원칙

블루프린트(컴포넌트 순서 고정) 방식이 아닌 **비율 제약 + 금지 패턴** 방식을 사용한다.
- 블루프린트: 모든 A시안이 똑같은 컴포넌트 순서 → 서비스마다 달라야 하는 특성 죽임
- 비율 제약: "카드 높이"/"화면에 보이는 아이템 수" 등 크기 규칙만 강제 → 서비스 맥락은 살아있음
- 금지 패턴: "A에는 B의 대형 히어로 없음" 명시 → 교차 오염 방지

---

## 변경 내용

### PHILOSOPHY_A — 정밀 정보형에 추가

기존 텍스트 뒤에 아래 섹션 추가:

```
## 크기·밀도 제약 (필수)
- 카드/아이템 높이: 모바일 기준 56~80px 이하의 compact 카드. 한 화면에 최소 5개 아이템이 동시에 보여야 한다.
- 상단 요약 영역: 전체 viewport 높이의 25% 이하로 제한한다. 요약 띠(summary strip) 하나 또는 KPI 수치 행 하나면 충분하다.
- 히어로 금지: 화면의 30% 이상을 차지하는 대형 히어로 패널, 풀블리드 이미지 카드, 몰입형 배경 불가.
- 이미지 비율 제한: 카드 내 이미지 영역은 카드 높이의 30% 이하. 아이콘/썸네일 수준으로 제한.
- B/C와의 차이: 대형 히어로 없음, 이미지 그리드 없음, 가로 스크롤 카테고리 없음 — 대신 스캔 가능한 compact list/table이 화면 대부분을 차지함.
```

### PHILOSOPHY_B — 전환 중심형에 추가

기존 텍스트 뒤에 아래 섹션 추가:

```
## 크기·집중 제약 (필수)
- 히어로 패널 크기: 화면 최상단에 viewport 높이의 38~48%를 차지하는 대형 히어로 패널이 반드시 있어야 한다. 배경색(primary 계열) 또는 이미지 + 큰 제목 + CTA 버튼으로 구성.
- Focal point 하나: 첫 화면에서 시선이 향하는 곳은 하나뿐이어야 한다. CTA 버튼이 hero 안 또는 hero 바로 아래에 위치.
- 아래 컨텐츠: 히어로 아래에는 추천 아이템 3개 이상이 이어짐. 단 카드 크기는 히어로보다 확연히 작아야 함(hierarchy 유지).
- A/C와의 차이: A의 compact list 구조 없음, C의 카테고리 가로 스크롤·이미지 그리드 없음 — 대신 하나의 강렬한 히어로가 화면의 절반을 지배함.
```

### PHILOSOPHY_C — 브랜드 탐색형에 추가

기존 텍스트 뒤에 아래 섹션 추가:

```
## 크기·이미지 제약 (필수)
- 이미지 비율: 카드 면적의 50% 이상이 이미지(또는 비주얼) 영역이어야 한다. 텍스트가 이미지보다 크면 실패.
- 탐색 구조 필수: 다음 중 하나가 반드시 있어야 함 — (1) 가로 스크롤 카테고리 rail, (2) 2열 이미지 그리드, (3) editorial 풀블리드 카드 + 아래 2열 그리드.
- 여백 확보: A보다 카드 간격이 넓어야 한다. 숨 쉬는 레이아웃.
- A/B와의 차이: A의 compact stats/list 위주 구조 없음, B의 단일 large CTA 집중 없음 — 대신 이미지와 카테고리가 탐색 경험을 이끔.
```

- **파일 1개만 수정:** `src/lib/variant-refs.ts`

## 기대 결과

| 시안 | 한 화면에 보이는 아이템 수 | 히어로 크기 | 이미지 비율 |
|---|---|---|---|
| A | 5개+ | 없거나 매우 작음 | 카드의 30% 이하 |
| B | 3개 이하 | viewport 40%+ | 히어로에만 집중 |
| C | 4~6개 | 에디토리얼 | 카드의 50%+ |

같은 디자인 시스템(색상/폰트/토큰) 유지 → 레이아웃 구조만 명확히 다름
