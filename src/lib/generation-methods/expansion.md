# 선택안의 멀티스크린 확장

## Input
사용자가 선택한 메인 HTML, 화면 목록·이동 목적, 공유 콘텐츠와 디자인 계약.

## Method
- 추가 화면마다 사용자가 해야 할 다음 행동과 필요한 콘텐츠를 연결한다. 메인 화면의 컴포넌트 표현·용어·밀도를 재사용한다.
- 다른 화면에서도 같은 객체의 이름·수치·상태와 같은 행동의 레이블을 유지한다. 연결 목적지와 data-screen 식별자를 기존 출력 계약에 맞춘다.
- 확장은 새 디자인 제안이 아니다. 필요하지 않은 화면·내비게이션·브랜드 요소를 발명하지 않는다.

## Output
아래의 기존 멀티스크린 출력 형식을 따른다. 공통 UI 고정·이미지 보존 지침을 유지한다.

## Guardrails
선택한 메인 화면은 수정 대상이 아니다. 최종 셸 조립과 메인 보존은 Aide 코드가 담당하며, 모델이 전체 HTML을 다시 디자인하지 않는다.
