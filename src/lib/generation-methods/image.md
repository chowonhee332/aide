# UI에 배치할 이미지 제작

## Input
선택한 소재, 참고 이미지, 팔레트 힌트와 호출에서 지정한 배경·구도·출력 모드.

## Method
- 소재의 정체성·형태를 유지한다. 참고 이미지는 지정된 스타일 근거이며 다른 서비스의 로고나 UI를 복제하는 근거가 아니다.
- 아래 제작 프롬프트의 배경·구도·크롭 조건을 지킨다. 투명 오브젝트용 출력에 장면 배경을 추가하거나 장면 출력의 배경을 임의로 제거하지 않는다.
- 주변 UI와 경쟁할 텍스트·버튼·차트·워터마크를 이미지 안에 새로 넣지 않는다. 텍스트와 상호작용은 HTML이 담당한다.

## Output
요청된 이미지 출력만 생성한다. 별도 도구 호출 지시나 UI 코드를 출력하지 않는다.

## Guardrails
이 지침은 이미지 생성 도구를 제공하지 않는다. 이미지 생성·후처리는 Aide가 연결한 Gemini 이미지 API와 실행 코드가 담당한다.
