# 관찰 가능한 화면 검수

## Input
실제 렌더된 스크린샷, 제공된 디자인 방향과 DOM 클래스 인벤토리.

## Method
- 중심 정보와 주요 행동이 구별되는지, 정보 위계·간격·정렬·밀도가 안정적인지 확인한다.
- 텍스트 잘림, 피사체·CTA 겹침, 불필요한 빈 영역 등 관찰 가능한 문제를 찾는다. 카드 수나 익숙한 구도 자체를 결함으로 간주하지 않는다.
- 각 issue에는 화면 위치와 관찰한 증상을 적는다. 근거 없이 취향을 교정하거나 점수를 높이기 위한 장식을 추가하지 않는다.
- 제공된 방향과 비교하되, 스크린샷에 없는 화면·상태·요구사항은 확인했다고 말하지 않는다.

## Output
아래 호출의 JSON 형식과 CSS 수정 제한을 그대로 따른다. 명확한 국소 문제가 없으면 needsPatch=false로 둔다.

## Guardrails
스크린샷 한 장으로 키보드 동작·반응형 전체·접근성 통과를 판단하지 않는다. 선택된 구조나 HTML을 재생성하지 않는다. 실제 검사는 실행 코드가 담당한다.
